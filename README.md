# Activity 1: California House Price Prediction

## Project Information
- **Subject:** Regression and Classification Algorithms
- **Activity:** Multiple Linear Regression Worksheet
- **Algorithm:** Single Linear Regression and Multiple Linear Regression
- **Dataset:** California Housing Dataset

## Problem Statement
The objective of this project is to predict the median house value in California using numerical features such as median income, house age, average rooms, population and geographical location.

## Dataset Source
California Housing Dataset provided by Scikit-learn.

Dataset documentation: https://scikit-learn.org/stable/datasets/real_world.html#california-housing-dataset

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Statsmodels

## Project Workflow
1. Dataset loading and exploration
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Correlation analysis and heatmap
5. Manual calculation of Linear Regression
6. Single Linear Regression implementation
7. Multiple Linear Regression implementation
8. Model evaluation using MAE, MSE, RMSE and R²
9. Residual analysis and VIF calculation
10. New house value prediction

## Project Files
- `Program.ipynb` – Complete project implementation and outputs.
- `data/california_housing.csv` – Dataset used for the project.

## Evaluation
The models are evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
- Adjusted R² Score

## Conclusion
The project demonstrates how Single and Multiple Linear Regression can be used to predict median house values using different numerical features. The performance of both models is compared using standard regression evaluation metrics.
